# WF-013 — Gestión de precios individuales y masivos

## Regla de consistencia
El primer precio del producto puede haber sido preparado automáticamente durante la creación del producto. Esta pantalla administra el precio una vez que Pricing es owner.

Para variantes:
- Mostrar “Hereda precio del producto” cuando no hay precio específico.
- Permitir configurar un override según el flujo de Pricing.
- No obligar a crear precio por variante durante el alta del SKU.

## No mostrar
Nombre del mensaje de inicialización ni detalles del broker.
