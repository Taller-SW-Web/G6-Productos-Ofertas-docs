# UX Decisions — Productos y Ofertas

> Registro transversal para justificar decisiones UX relevantes del módulo.

## 1. Regla de uso

Crear `UXD-XXX` cuando una decisión:

- Afecta varias funcionalidades.
- Define un patrón recurrente.
- Tiene alternativas razonables.
- Implica un trade-off.
- Debe poder defenderse ante el profesor.

No usar este archivo para repetir tokens o componentes ya definidos por el Design System.
