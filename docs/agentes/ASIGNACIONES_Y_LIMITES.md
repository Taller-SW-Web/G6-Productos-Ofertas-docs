Backend #54 y frontend #3/#10/#15/#16 figuran cerrados. Se conserva el contenido para estudiar o revisar evidencia; no se reabre ni se repite implementación mediante esta tarea.

Frontend #3/#15/#16 conserva instrucciones históricas para crear ramas de feature. Las carpetas de esta colección indican la rama convencional del responsable. Al ejecutar un encargo nuevo, leer la política vigente y la instrucción humana: esta documentación no crea ramas ni impone la política de backend a frontend.

Docs se encuentra en lab/lopez, cuyo README prohíbe PR y merge a ramas oficiales. El usuario autorizó esta colección documental en docs; no autorizó publicación ni modificación de la UX transversal.

## Issues y evidencia

La copia del issue acredita el contenido consultado y su asignación/estado en ese corte. El encargo derivado acredita la documentación de instrucciones preparada ahora. Una ejecución de IA necesita evidencia adicional: sesión, archivos/diff, decisiones humanas y resultados. Consultar la [guía de uso de IA](../uso-ia/README.md).
